# PiyushDhara

PiyushDhara is an ed-tech project created to support structured learning, digital academic engagement, and accessible education-focused workflows for students, educators, and administrators.

The project is designed for an education organization that wants to present learning resources, manage academic information, and deliver a professional digital experience around its programs and services.

## Overview

PiyushDhara focuses on creating a clean, reliable, and user-friendly education platform. It can be used as the foundation for an institutional website, learning portal, student support system, or digital education service depending on the final implementation.

## Key Features

- Professional ed-tech focused user experience
- Student-friendly interface for accessing educational content and services
- Organization profile and program presentation
- Scalable structure for adding courses, resources, announcements, and learning modules
- Clean project organization suitable for future development and maintenance
- GitHub-ready documentation for collaboration and deployment

## Project Goals

- Improve access to educational resources
- Provide a digital identity for the PiyushDhara organization
- Support learners with organized academic information
- Help educators and administrators manage education-related content efficiently
- Build a maintainable base for future feature expansion

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Install the tools required by your project, such as:

- Git
- Node.js and npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Official-Vinit/PiyushDhara-Ed-tech.git
```

Install dependencies and run backend:

```bash
cd backend
npm install
npm run dev
``


Install dependencies and run frontend:

```bash
cd frontend
npm install
npm run dev

cd frontend-admin
npm install
npm run dev
```

Open the local URL shown in your terminal, usually:

```text
http://localhost:3000
```
